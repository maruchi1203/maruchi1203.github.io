## 개발 중인 프로젝트입니다

## 프로젝트 환경
- 언어 : Typescript
- 프레임워크 : React
- 번들러 : VITE
- 프론트엔드 배포용 패키지 : github-pages
- 백엔드 : Render

## 블로그 제작 의도
Github API와 Velog RSS를 이용하여 제 오픈소스와 작성글 등을 한 곳에 보여주는 블로그를 만들고자 했습니다. 포트폴리오나 여러 가지 글 등을 올릴 예정입니다.
