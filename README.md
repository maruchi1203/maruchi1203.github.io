## 프로젝트 환경

- Framework  : React (w/ Next.js)
- FE 배포 환경 : GitHub Pages + Actions
- BE 배포 환경 : Render

## 개발 목표

- GitHub의 Public 프로젝트 출력
- Velog의 RSS 피드 데이터 출력
- 개인 글
